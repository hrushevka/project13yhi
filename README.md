# [Cosmos lab](https://cosmoslab.ddns.net/)

Симуляция проблемы Трёх космических тел.

<img src="src/assets/Cosmos lab.gif" alt="Пример GIF" style="width: 100%; height: 400px; object-fit: cover; object-position: center; display: block;">

На сайте представленна симуляция - песочница, с большим количеством стагдартных конфигурация, детерминированой и проработаной физикой.

для запуска:
```powershell
npm install
npm run dev
```
в консоли
и откройте http://localhost:2283 в браузере

для проверки и конечного билда:
```powershell
npm run lint
npm test
npm run build
npm run preview
```
в консоли
и откройте в браузере выведеный порт. Также в папке `dist` будет статический HTTP сайт.
